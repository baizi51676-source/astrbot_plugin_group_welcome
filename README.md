# 🎉 Group Welcome · 入群欢迎插件

> 适用于 AstrBot 的入群欢迎插件，支持欢迎图片、AI 个性化欢迎、群专属欢迎语、私聊群规、黑白名单管理。
>
> **v2.6.0 新增**：🤖 多 bot 支持（一个 AstrBot 多个 QQ 号，各 bot 独立欢迎、事件按 bot 路由，可用 `welcome_bots` 指定启用范围）· 🔌 SnowLuma 兼容 · 📦 模板库可绑定 bot（`bot_ids` + 专属模式 `exclusive`）


---

## 依赖说明

- 本插件**仅验证过支持 OneBot 11 协议**（NapCat / SnowLuma 等 OneBot v11 实现均可接入，推荐 AstrBot 使用 aiocqhttp 适配器）。
- 建议使用 AstrBot v4.12.0 或以上版本。
- 若机器人启动后欢迎未触发，请尝试**重启机器人**或**重载插件**（多 bot 场景下新增/启停某个 bot 后同样需要重载插件以重新注册监听）。

---

## 功能特性

- **群欢迎模板库**：可在后台维护多套欢迎模板，按群号匹配，命中群优先使用模板配置；模板未填写的项自动回退到全局配置；v2.6.0 起模板可绑定 bot（`bot_ids`），并支持「专属模式」让某群只由指定 bot 欢迎
- **群专属欢迎语**：可为不同群单独设置欢迎内容，未设置的群使用全局默认。
- **AI 个性化欢迎**：调用 AstrBot 配置的大模型，根据新成员昵称生成一句定制欢迎语，支持指定模型、失败重试。
- **欢迎图片池**：可配置多张欢迎图片，每次入群**随机发送一张**，支持网络 URL 或本地路径。
- **群人数统计**：欢迎语中可追加"你是当前群里第 X 位成员"。
- **私聊发送群规**：新人入群后尝试私聊发送群规内容（默认关闭，防风控）。
- **黑白名单**：灵活控制哪些群启用欢迎功能。
- **防刷屏冷却**：同一用户短时间内重复入群不重复触发。
- **冷却数据持久化**：重启后冷却记录不丢失。
- **多 bot（v2.6.0）**：一个 AstrBot 挂多个 QQ 号（多个 aiocqhttp 实例）时，为每个 bot 独立注册入群监听，事件按 bot（self_id）路由——各 bot 只欢迎自己群里的新人，互不串号；可用 `welcome_bots` 只启用其中部分 bot。
- **SnowLuma 兼容（v2.6.0）**：NapCat 官方姊妹项目（同为 OneBot v11），事件与所用 API 协议级兼容，接入无需任何额外配置。

## 安装

将插件文件夹（含 `main.py`、`_conf_schema.json`、`metadata.yaml`）放入 AstrBot 的 `data/plugins/` 目录，重启 AstrBot 即可。

## 后台配置（WebUI）

进入 AstrBot 后台 → 插件配置页面，可设置以下项目：

| 配置项 | 说明 | 默认值 |
|:--|:--|:--|
| 🎉 全局默认欢迎语 | 支持变量 `{name}`（昵称）、`{count_text}`（第几位成员） | 内置默认语 |
| 📦 群欢迎模板库 | 按群号匹配，命中群优先使用模板配置（详见下方优先级说明） | 空 |
| 🤖 启用欢迎的 bot（v2.6.0） | 多 bot 时填写平台实例 id 或登录 QQ 号 = 只在这些 bot 上触发欢迎；留空 = 全部 bot | 空（全部）|
| ✅ 白名单群号 | 每行一个群号，填写后只有这些群触发欢迎 | 空 |
| 🚫 黑名单群号 | 每行一个群号，白名单为空时生效 | 空 |
| 📊 开启群人数统计 | 欢迎语末尾追加成员序号 | 开启 |
| 📩 开启私聊群规 | 新人入群后尝试私聊发送群规 | 关闭 |
| 📜 群规内容 | 私聊发送的具体文字 | 内置示例 |
| 🤖 开启 AI 个性化欢迎 | 调用大模型生成一句定制欢迎语 | 关闭 |
| 🧠 AI 模型提供商 | 指定用于生成欢迎语的模型，留空使用系统默认 | 空（系统默认） |
| 🔄 AI 重试次数 | AI 生成失败后的重试次数，0 表示不重试 | 0 |
| 📝 AI 提示词 | 指导 AI 生成内容，支持 `{name}` 变量 | 内置提示词 |
| 🖼️ 欢迎图片池 | 可填多张图片 URL 或本地路径，每次随机发送一张 | 空（不发送） |
| ⏱️ 防刷屏冷却（秒） | 同一用户重复入群的最小触发间隔 | 300 秒 |

### 模板库优先级说明

配置优先级从高到低为：

1. **模板库**：`group_ids` 中包含当前群的模板。
   - 同群存在多条匹配模板时，**bot 专属模板（`bot_ids` 含当前 bot）优先于通用模板（`bot_ids` 留空）**；
   - 模板中的开关项（如群人数统计、私聊群规、AI欢迎）始终以模板为准；文本/图片列表项留空时回退到下一级。
2. **群专属欢迎语**：通过 `/welcome set` 指令设置的旧版群欢迎语。
3. **全局默认配置**：上方表格中的全局配置项。

> **v2.6.0 模板绑定 bot（`bot_ids` / 专属模式 `exclusive`）**
>
> - 模板条目新增「适用 bot」(`bot_ids`)：填写登录 QQ 号后，该模板**只对名单内的 bot 生效**（多 bot 各管各的群时，可为不同 bot 建各自的模板库条目，互不干扰）；
> - 勾选「专属模式」(`exclusive`) 后：命中该模板的群**只由名单内 bot 负责欢迎**，其他 bot 即使也在群里也会跳过（防止同群多 bot 重复欢迎）；
> - 被其他 bot 以专属模式认领的群，通用模板对该 bot 不再生效；
> - 旧的模板条目没有 `bot_ids`/`exclusive` 字段时视为通用模板，行为与旧版完全一致。

> 旧版配置（白名单、黑名单、群专属欢迎语等）完全兼容，不配置模板库时行为与旧版一致。

> ⚠️ **请勿在 WebUI 中手动修改「群专属配置」字段**，该字段由系统自动维护，手动编辑可能导致 JSON 损坏。请使用 `/welcome set` 指令进行配置。

## 指令列表

所有指令需要**管理员权限**。指令前缀默认为 `/`，请根据你的 AstrBot 配置调整。

### 欢迎语设置

| 场景 | 指令 | 说明 |
|:--|:--|:--|
| 群聊 | `/welcome set 欢迎 {name} 加入！` | 设置本群专属欢迎语 |
| 群聊 | `/welcome set reset` | 清除本群设置，恢复全局默认 |
| 群聊 | `/welcome set show` | 查看本群当前欢迎语 |
| 私聊 | `/welcome set <群号> 欢迎 {name} 加入！` | 为指定群设置欢迎语 |
| 私聊 | `/welcome set reset <群号>` | 清除指定群设置 |
| 私聊 | `/welcome set show <群号>` | 查看指定群当前欢迎语 |

### 状态查询

| 指令 | 说明 |
|:--|:--|
| `/welcome status`（群聊） | 查看插件状态 + 本群欢迎语及来源 |
| `/welcome status`（私聊） | 查看插件状态 + 已自定义群的数量 |
| `/welcome status <群号>`（私聊） | 查看插件状态 + 指定群欢迎语 |

### 功能开关

| 指令 | 说明 |
|:--|:--|
| `/welcome count on/off` | 开启 / 关闭群人数统计 |
| `/welcome rules on/off` | 开启 / 关闭私聊群规 |
| `/welcome ai on/off` | 开启 / 关闭 AI 个性化欢迎 |

### 黑白名单

白名单不为空时，只有白名单内的群会触发欢迎；白名单为空时，黑名单内的群不触发欢迎。

| 指令 | 说明 |
|:--|:--|
| `/welcome wl add <群号>` | 加入白名单 |
| `/welcome wl del <群号>` | 移出白名单 |
| `/welcome wl list` | 查看白名单 |
| `/welcome bl add <群号>` | 加入黑名单 |
| `/welcome bl del <群号>` | 移出黑名单 |
| `/welcome bl list` | 查看黑名单 |

## 常见问题

**Q：一个 AstrBot 挂了多个 QQ 号，怎么让每个 bot 各自欢迎？**

默认（`welcome_bots` 留空）就会**自动为每个 bot 独立欢迎**——插件为每个 aiocqhttp 实例分别注册入群监听，事件按 bot（self_id）路由，bot A 只欢迎 bot A 群里的新人。若只想让其中部分 bot 启用，在「🤖 启用欢迎的 bot」里填写对应平台实例 id 或 QQ 号即可。

**Q：两个 bot 在同一个群，会重复欢迎吗？**

会（两个 bot 都会收到该群的入群通知）。解决办法：在该群的模板条目的「适用 bot」中只填一个 bot 的 QQ 号，并勾选「专属模式」(`exclusive`)——另一个 bot 在该群会自动跳过欢迎。

**Q：从 NapCat 换成 SnowLuma 需要改配置吗？**

不需要。SnowLuma 与 NapCat 同为 OneBot v11 实现，本插件用到的入群事件（`group_increase`）与 API（成员信息/群信息/发消息）协议级兼容，AstrBot 侧把 aiocqhttp 适配器连到 SnowLuma 即可。

**Q：开启了私聊群规，但新人没收到私聊？**

新成员可能关闭了"允许陌生人发起临时会话"，或当前平台风控限制了临时会话。建议将重要群规直接写在群欢迎语中。

**Q：AI 欢迎开启了，但没有生效？**

请确认：① 已执行 `/welcome ai on`；② AstrBot 已配置可用的大模型（平时 @ 机器人能正常回复即可）；③ 若指定了模型，确认该模型 ID 填写正确。

**Q：如何为不同群指定不同的 AI 模型？**

可在"群欢迎模板库"中为指定群号单独配置"AI 模型提供商"，模板配置优先于全局；未配置模板或模板留空的群使用全局设置。

**Q：配置了欢迎图片但群里没显示？**

请确认图片 URL 可直接在浏览器打开，且 OneBot 客户端能正常访问。部分客户端可能不支持某些图片格式或过大的文件。图片池中每张图片都会随机发送，若某张无法访问会正常发送其余图片。

## AI 功能使用声明

启用"AI 个性化欢迎"功能即表示您同意以下条款：

1. **数据传输**：本插件仅将新成员的**公开昵称**发送给您配置的大语言模型，不涉及 QQ 号或其他私密信息。
2. **内容免责**：AI 生成内容由您所配置的模型提供，插件开发者不对内容的准确性或适宜性作任何保证。
3. **费用说明**：启用此功能将消耗您配置的模型服务的 API 调用额度，请根据实际需求酌情使用。
